# Tongo

> Tongo is a confidential payment protocol for ERC-20 tokens on Starknet. It wraps any ERC-20 with ElGamal encryption and zero-knowledge proofs so transfer amounts stay hidden while remaining verifiable on-chain — no trusted setup, no oracles, no TEEs, no external servers. Optional auditor keys provide compliance via selective disclosure.

The current protocol version is **v2**, which splits the protocol into a per-asset **Vault** (holds the ERC-20 reserve, deploys ledgers) and **Tongo Ledger** instances (hold encrypted balances, verify proofs), adds **external transfers** between ledgers of the same Vault, and introduces a **Relayer** that lets users operate **gasless — without a Starknet account** (SNIP-9 outside execution paid through the AVNU paymaster and reimbursed from the operation fee). The v1 (legacy) docs remain available under `/v1/`.

Tongo is built by Fat Solutions. The cryptography is based on the paper "Zether: Towards Privacy in a Smart Contract World" (https://eprint.iacr.org/2019/191).
